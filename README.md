# 📏 Measure Game
An interactive, educational math game designed to help learners understand, practice, and master units of measurement, ruler reading, and spatial estimation in a fun and engaging way!

## 🚀 Features
- **Interactive Measurement Challenges:** Measure objects using virtual rulers, scales, or interactive tools.
- **Unit Practice:** Practice reading lengths, heights, and distances across different measurement units (e.g., cm, mm, inches).
- **Progressive Levels:** Challenges scale in precision, from whole numbers down to precise fractional or decimal increments.
- **Real-Time Feedback:** Immediate visual cues to help players refine accuracy and estimation skills.
- **Clean & Lightweight:** Optimized for smooth performance with zero unnecessary dependencies.

## 🎮 How to Play
1. Start a new game session.
2. Read the measurement prompt or examine the item presented on the screen.
3. Drag or align the measurement tool (e.g., ruler/tape) to read the object's dimensions, or enter the correct value.
4. Submit your answer to score points and advance to the next challenge!
